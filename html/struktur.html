Di dalam HTML, struktur merujuk pada cara elemen-elemen HTML disusun untuk membentuk sebuah halaman web yang dapat ditampilkan di browser. Struktur HTML terdiri dari berbagai elemen yang membentuk layout dan konten dari halaman tersebut. Elemen-elemen ini saling terhubung dalam hierarki tertentu. apa fungsi tag didalam html

Apa yang di maksud tag dalam html

Tag HTML adalah elemen dasar dalam penulisan kode HTML yang digunakan untuk membungkus atau menandai berbagai jenis konten pada halaman web. Tag HTML biasanya terdiri dari pasangan pembuka dan penutup, dengan konten yang terletak di antaranya. Setiap tag HTML memiliki tujuan tertentu untuk menentukan bagaimana konten harus ditampilkan atau diproses oleh browser.

Gambar diatas sebagai contoh Tag-tag HTML mari kita jelaskan satu-persatu:

1. kegunaan Tag <HTML></HTML>

kegunaan tag <HTML></HTML> yaitu sebagai pembungkus html kita supaya html kita bisa di jalankan di broser kita supaya yang lain bisa melihatnya kalau kita hilangkan tag tersebut dia akan berantakan web kitan bahkan akan menjadi hancur.

2. Kegunaan tag <Head></Head>

Tag <Head></Head> berfungsi sebagai buat menaruh link atau Penghubung antara HTML kita ke sebuah css atau yang lainnya, Ya di sebut mudahnya dia kerjanya penghubung jalan antara kota1 ke kota2

3. kegunaan Tag <Body></Body>

Nah si tag <Body></Body> ini dia gunanya supaya web kita tampilya ke broser nah itu dia kerjanya Memunculkan artikel kita kedalam broser supaya bisa di lihat oleh User
