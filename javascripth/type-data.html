macam macam type data di javascript

Apa yang di maksud dengan type data

Type data adalah kalau kita di ibaratkan seperti hp yang mempunyai tipe yang banyak dan masing masing tipe itu berbeda kaya tipe hp 1 pasti berbeda dengan tipe hp 2 begitu pula dengan type data di javascript. Dan javascript kalo kalian tau mempunyai 2 inti type data yaitu:

type data primitif


Apa yang di maksud dengan tipedata primitif



Type data primitif yaitu tipe data yang tidak bisa di ubah nah maksudnya klo kita nulis 1 pasti keluarnya 1 kita tidak bisa mengganti dengan kita tambahkan variable baru, Klo mau di ubah ya pasti kita hapus yang kita buat awal nah kita sebutkan macam-macam tipe data primitif:

1 Type data string

Nah ciri has si data string itu dia pasti mempunyai tanda("", '', ``) nah dia juga bisa di gunakan untuk kalimat atau kata seperti gambar di atas

2 Type data number





Type data number adalah type data yang bersifat nomor ya sepertih contoh diatas aja dia bersifat nomor maupun nomor desimal, ataupun pecahan. Nah ciri khas dia tidak menggunakan tanda apapun tidak seperti string kalo dia langsung di tulis aja dan dia sering di gunakan untuk sebuah nomor

3 Type data bolean





Nah kita akan menjelaskan apasi type data bolean?, Type data bolean adalah type data untuk mengecek suatu kebenaran dan salah nah type data ini sering di gunakan sama user ketika dia ingin mengecek sesatu jika benar. Dan itu biasanya di gabung dengan komponent if

4 Type data Syimbol





Nah gambar diatas menunjukan tipe data syembol walaupun tipe data ini jarang di gunakan apa salahnya kita mengenal soalnya kan ini masih bagian javascript dan juga dia ada kegunaan tersendiri yaitu untuk membuat syimbol dan dia mempunyai cirikhas yaitu menggunakan kata < Syembol >

5 Type data BigInt





Nah BigInt adalah kegunaanya hampir sama dengan type data number yang kegunnanya untuk nomor. Akan tetapi dia mempunyai cirikhas sendiri yaitu untuk menampung data besar pada number

5 Type data undefind





Yaitu apa bila si type datanaya tidak di isikan sesuatu dia akan muncul atau menjadi undifend yang artinya dia tidak ada isinya dan apabila variablenya di bungkus dengan const dia akan eror karena const dia harus kontan / lunas

Nah diatas itu contoh type data primitif

type data referensi


Nah type data ini yaitu dia yang menyimpan isi tersebut langsung kedalam memori dan mari kita liat macam-macam type data referensi:

1 type data object





Type data object kegunaanya yaitu apabila kita ingin menambahkan data nama, sekolah dll dalam satu memori kita bisa menggunakan type data object

2 type data date





Type data date kegunaanya yaitu apabila kita ingin menambahkan sebuah waktu kayak tanggal, hari, tahun kita bisa menggunakan type data ini

3 type data array





Type data array kegunaanya yaitu apabila kita ingin menggunakan lebih leluasa kita mau isikan di dalamnya sebuah bolean int ataupun string dia bisa

nah diatas kita menjelaskan tentang sebuah macam macam type data dia memiliki tersendiri kita bisa mengunakanya sesuai keinginan kita
